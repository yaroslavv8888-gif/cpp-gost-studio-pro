# Схема Studio Pro

Студия преобразования C++ в редактируемые блок-схемы.

## Запуск

Откройте STUDIO.html в браузере или запустите START_ON_PC.bat. После обновления движка нажмите «Построить схему»: сохранённые чертежи автоматически не заменяются.

## Разработка и сборка

Установите Node.js и зависимости командой npm install. API-ключи не требуются.

    node node_modules/vite/bin/vite.js
    node build-standalone.mjs

Вторая команда сама запускает свежую Vite-сборку и обновляет public/standalone-pc.js, public/standalone-pc.css, STUDIO.html и ЗАПУСК_НА_ПК.html. Готовую страницу можно открывать без сервера. Резервные копии не используются при сборке.

## Проверки

    node test-engine.mjs

Проверка запускает TypeScript, тесты модулей и сравнение исходного/восстановленного C++ на разных входных данных. Для последней проверки нужен g++ в PATH либо путь к компилятору в CXX; отсутствие компилятора вызывает ошибку, а не пропуск теста.

## Правила оформления

Движок использует рекурсивную компоновку ветвей, ортогональную маршрутизацию и диагностические проверки. Проектные соглашения (один «Конец» на функцию, объединения перед входом в блок, до трёх непосредственных выходов решения и исходные подписи ввода/вывода C++) отделены от утверждений о ГОСТ.

Проверки не являются сертификацией полного соответствия стандарту или полноценным компилятором всего языка C++. Явные пользовательские точки маршрута сохраняются; их пересечения выявляются валидатором.
