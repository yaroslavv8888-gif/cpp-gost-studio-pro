# Схема Studio Pro

Рабочая студия для студентов и преподавателей: преобразование C++ в блок-схемы, ручная правка и экспорт.

Палитра: фарфор #F5F7F9, белый #FFFFFF, графит #202D3D, сталь #D9E1E8, синий #245BC4, зелёный #24735C.
Интерфейс: Golos Text с запасным Segoe UI. Код: JetBrains Mono с запасным Consolas. Автономный HTML не требует загрузки шрифтов.

```
Знак и название       Документ и стандарт        Экспорт
Панель кода / история / лист / рамка / проверка
┌────────────────┬───────────────────────┬──────────────┐
│ main.cpp       │ Линейки               │ Символы      │
│ Исходный код   │                       │ Проверка     │
│                │ Блок-схема            │              │
│ Настройки      │                       │ Группы фигур │
│ Построить      │ Масштаб / координаты  │              │
└────────────────┴───────────────────────┴──────────────┘
```

Текст и инструменты выравниваются влево; библиотечные фигуры центрируются для сравнения геометрии. На узких экранах панели переходят в вертикальную компоновку.

Пересмотр плана: вместо универсальной тёмной панели и разноцветных кнопок — светлая оболочка, тёмная поверхность только для кода. Главный визуальный элемент — существующий чертёж с координатными линейками. Убраны декоративная нумерация групп, второстепенные подписи фигур и постоянно раскрытые настройки.

Сборка: `npm install`, `npm run build`, `node build-standalone.mjs`. Последняя команда обновляет автономную страницу и файлы public/standalone-pc.*.
